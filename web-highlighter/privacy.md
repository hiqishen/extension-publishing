# 网页划线高亮隐私政策

更新日期：2026-09-30；适用于 0.2.0。

## 处理的数据和用途

扩展在普通网页读取可见文字及页面结构，用于选区高亮和恢复定位。阅读记录包含页面网址、标题、高亮原文及上下文、锚点、颜色、批注、标签、创建和修改时间。用户主动保存正文时，扩展在设备上提取正文 Markdown，并生成纯文本搜索索引。导入文件中的相应资料用于恢复和整理资料库。页面内容和批注可能含个人或敏感信息，请谨慎选择保存与同步内容。

这些资料默认保存在当前浏览器的 `chrome.storage.local`，用于高亮恢复、编辑、搜索、导入导出和同步合并。扩展不读取 Chrome 浏览历史数据库、Cookie 或网站密码，不收集广告标识，不内置广告、分析统计或开发者服务器上传。

## 可选同步和网络传输

无需注册扩展账号，本地功能无需 WebDAV。用户配置 WebDAV 时，服务器地址、用户名、密码、同步目录、自动同步选项及间隔保存在 `chrome.storage.sync`；Chrome 账号同步开启且扩展 ID 一致时，配置可由 Chrome 同步到其他浏览器。密码也属于同步配置，扩展没有为其提供独立端到端加密；请使用专用且权限受限的 WebDAV 凭据。

“保存配置（不同步）”只保存配置，不访问 WebDAV。“测试连接（只读）”向用户指定的服务器发送认证信息和读取请求，不上传资料。“连接并同步”拉取、合并并上传资料，成功后建立当前设备的活动连接；之后手动同步或开启的定时同步会与该服务器交换页面、高亮、批注、标签、正文、删除记录和同步元数据。凭据用于 WebDAV HTTP Basic 认证。公网服务器要求 HTTPS；仅本机回环地址允许 HTTP。

WebDAV 资料使用 JSON、gzip 和内容哈希组织，不构成内容加密。服务器运营者可能访问存储的资料和请求信息，其保留及处理规则由用户所选服务决定。扩展不会将资料发送给开发者或广告服务，不出售数据，不用于信用评估或贷款，也不用于与上述阅读和同步功能无关的用途。

## 保留、删除与控制

资料不设自动过期时间，可在资料库删除高亮、批量删除，或导出备份。删除会保留用于同步的删除记录；撤销快照及同步冲突可能保留可恢复内容。不可变远端日志与正文不会因界面删除而被物理清除。

“断开同步”停止当前设备的活动连接和定时同步，保留已保存的配置、本地资料和远端资料。若要彻底清除，应先备份，清除该扩展的本地浏览器存储和 Chrome 同步存储中当前及旧版 WebDAV 配置，并在所选 WebDAV 服务删除同步目录、历史版本和备份。仅卸载扩展不能保证其他设备、Chrome 同步服务或 WebDAV 的副本已删除；如需撤销凭据，请在 WebDAV 服务端更换或撤销专用密码。浏览器与服务器的备份和保留机制以其设置为准。

## 权限与支持

`storage` 用于本地资料与同步配置；`sidePanel` 用于当前网页高亮工作区；`alarms` 用于可选定时同步；所有网址的主机权限用于在普通网页响应文字选区、恢复高亮，以及连接用户自行指定的 WebDAV 服务。扩展商店、浏览器内部页面等受保护页面无法注入。扩展执行代码全部随安装包提供，不下载执行远程代码。

可通过商店支持入口或本产品支持页面提出问题。反馈请勿附带密码、令牌或未经脱敏的资料库导出文件。
