# 网页划线高亮使用与支持

更新日期：2026-11-02；适用于 0.2.5；需要 Chrome 120 或更新版本。

## 开始使用

1. 在普通 HTML 网页选中文字，通过浮动工具条选择高亮颜色。
2. 点击扩展图标打开当前页侧栏，编辑批注、颜色与标签；批注中输入 `#` 可选择或创建标签，支持 `#父级/子级`。
3. 从侧栏进入资料库，左侧切换划线、快捷键、同步和导入导出。搜索页面、原文、批注和标签，按需保存正文、整理标签或导出 JSON/Markdown。正文保存是用户主动操作。
4. 刷新原网页验证高亮恢复。页面发生较大变动时可能显示冲突，需要重新选中文字定位。
5. 在资料库右侧点击网页标题或网址打开原文；点击划线原文则打开对应网页并滚动到高亮。已打开的同一网页会优先复用标签页；左侧网页列表继续用于筛选。

划线原文可用键盘回车或空格触发。拖选复制文字、勾选、编辑和删除不会顺带打开网页。跳转后返回资料库，未保存的批注和标签草稿仍会保留。

定位外圈覆盖该划线的所有文本片段，颜色与划线填充色明显区分，保留到下一次点击网页后清除。普通文字与行内代码间的短空白断口会补齐；不同划线、不同段落及较大间隔不会连成一片。

侧栏和资料库的划线列表默认“按位置”，从当前网页顶部到底部排列；“按时间”按划线创建时间从早到晚排列，编辑批注不改变时间顺序。侧栏切回“按位置”或点击“刷新”会重读当前网页位置。资料库在每个网页分组内排序，优先读取已打开原网页的位置；未打开或无法读取时使用保存位置，并标明来源，不会自动打开网页。两处分别记住排序，切换时保留编辑草稿；资料库也保留搜索、筛选与勾选。

默认快捷键：macOS `Control+H`，Windows/Linux `Ctrl+Shift+H`。可在 Chrome 扩展快捷键管理页修改。

## 可选 WebDAV

在左侧“同步”页输入 HTTPS WebDAV 地址及专用用户名、密码、目录。点击“测试连接”或“同步”均会先保存配置，后续请求失败也不会清除已保存的配置。已有密码时输入框用 `****` 提示；地址、用户名和同步目录未变时，不输入新密码会沿用已保存的密码。

“测试连接”只检查所填 WebDAV 地址对应目录的读取能力，不上传阅读资料，也不能证明同步目录可写。“同步”会拉取、合并并上传资料。“自动同步”只调整当前浏览器活动连接的后台同步设置。开启后从下一次所设间隔开始运行，不立即同步；关闭后停止后续后台同步，保留活动连接、配置和资料，仍可点击“同步”手动处理。未连接时先点击“同步”。同步或连接测试期间也能切换开关，当前操作结束后保存并生效；未提交的地址、密码和间隔不会因切换开关而应用。

Chrome 账号同步只传输配置（包括密码），不传输正文或高亮；换设备后需先点击“同步”建立当前浏览器的活动连接，再按需开启自动同步。请让所有设备使用兼容当前同步协议的版本。删除记录用于跨设备传播，远端旧日志和正文不会被自动物理删除。完整的数据处理与删除说明见隐私政策。

## 故障处理

- 浏览器内部页、Chrome 应用商店、PDF 和部分受保护页面不支持高亮；本版不提供图片高亮。
- 更新扩展后刷新原网页；选区工具条未出现时检查扩展是否允许访问该网站。
- 高亮恢复失败时从侧栏查看冲突并重新定位，避免将网页变更后的相似文字误当原文。
- 从资料库定位时，网页内容已变化、存在多个匹配位置、网页不允许扩展运行或加载超时都会提示原因。本机文件需要为扩展开启文件网址访问权限；其他扩展的受保护阅读器页面可能无法定位。
- WebDAV 失败时检查地址、认证、目录权限及服务端列举能力；有 HTTP 状态码时可据此排查服务端响应。测试成功后同步仍可能因目录或写入权限失败。请求失败会保留配置和本地资料。不要通过卸载重装或更换扩展目录迁移数据，迁移前先导出备份。
- 同步冲突可在同步设置中导出冲突 JSON；导出不会清除恢复分支。不要公开包含私人内容的文件。

## 反馈

通过 Chrome 应用商店的支持入口反馈，附上扩展版本、Chrome 版本、最小复现步骤、已脱敏截图及错误提示。不要提交账号、密码、令牌、私人网址或完整资料库。反馈前可用公开或本地示例网页复现。
