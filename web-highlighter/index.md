# 网页划线高亮

在普通网页上划线高亮、添加批注和多层级标签，并把阅读资料保存在浏览器本地。资料库支持全文搜索、JSON 与 Markdown 导入导出，以及可选的 WebDAV 跨设备同步。

## 使用方式

1. 在支持的 Chrome 中安装扩展，打开普通网页并选中文字。
2. 选择高亮颜色，打开侧边栏查看、编辑批注和标签。
3. 打开资料库跨页面搜索资料，按需保存正文 Markdown 或导出备份。
4. 在资料库左侧切换划线、快捷键、同步和导入导出。需要跨设备同步时配置自己的 WebDAV，点击“测试连接”或“同步”均先保存配置。测试只读取所填 WebDAV 地址对应目录；自动同步由一个开关控制，关闭后仍可手动同步。

Chrome 120 及以上版本可用。Chrome 内部页和扩展商店等受保护页面无法注入高亮；当前不支持 PDF 或图片高亮。
