# 网页划线高亮

资料更新日期：2026-11-11；适用版本：0.2.6。

在普通网页上划线高亮、添加批注和多层级标签，并把阅读资料保存在浏览器本地。资料库支持全文搜索、JSON 与 Markdown 导入导出，以及可选的 WebDAV 跨设备同步。侧栏与资料库分别提供按网页位置、划线创建时间排序，时间从早到晚；资料库按网页分组排列，标明当前位置或保存位置来源。

表格支持跨列、跨行及表头文字高亮，保留单元格与表格结构。更新扩展后刷新原网页，已有表格划线会按保存的锚点重新绘制。

## 使用方式

1. 在支持的 Chrome 中安装扩展，打开普通网页并选中文字。
2. 选择高亮颜色，打开侧边栏查看、编辑批注和标签。
3. 打开资料库跨页面搜索资料，按需保存正文 Markdown 或导出备份。
4. 在资料库左侧切换划线、快捷键、同步和导入导出。需要跨设备同步时配置自己的 WebDAV，点击“测试连接”或“同步”均先保存配置。测试只读取所填 WebDAV 地址对应目录；首次点击“同步”建立当前浏览器的活动连接；自动同步开关不立即发起同步，同步或测试期间也能切换，当前操作结束后生效。关闭后保留连接和资料，仍可手动同步。

Chrome 120 及以上版本可用。Chrome 内部页和扩展商店等受保护页面无法注入高亮；当前不支持 PDF 或图片高亮。

在资料库点击网页标题或网址打开原文，点击划线原文定位对应文字，优先复用已打开标签。定位外圈覆盖整条划线的全部片段，点击网页后清除外圈并保留高亮。原文发生变化或无法唯一定位时会提示原因。
