# Local Markdown Search 隐私说明

Local Markdown Search 通过 Chrome 地址栏和扩展弹窗搜索用户指定目录中的 Markdown 文件。使用搜索功能需要单独安装本机搜索助手。扩展不要求账号，不向开发者服务器发送文件、路径或搜索词，也不包含广告或开发者遥测。

## 处理的数据

- 本机助手在用户指定目录中扫描 `.md` 文件，并在设备上保存目录配置、文件名、完整路径、所属目录、修改时间、文件大小、索引更新时间，以及用户选择文件的次数和时间。索引不保存 Markdown 正文。
- 搜索词由扩展通过 Chrome Native Messaging 发送给本机助手，用于查询本机索引。搜索词不会由本产品保存到索引或发送给开发者。Chrome 可能按浏览器自身的历史记录设置处理地址栏输入。
- 用户选择打开文件时，扩展用 `file://` 地址在 Chrome 中打开该文件，并让本机助手记录选择次数。扩展内的文件查看页面需要读取内容时，本机助手只读取索引中的目标文件，且单个文件不超过 5 MB；正文只返回给当前扩展页面，不保存到索引。
- 是否使用正则搜索、正则匹配范围和单次最多结果数保存在 `chrome.storage.sync`。启用 Chrome 同步时，这些偏好设置可能由 Chrome 在用户设备间同步。搜索目录、文件索引、完整路径、选择记录和 Markdown 正文不写入该同步存储。

## 网络与第三方

扩展运行时不向开发者服务器发起请求，也不加载远程代码。首次运行本机助手的安装程序时，如果设备没有 `uv`，安装程序会在用户确认后从 `astral.sh` 获取 `uv`；`uv` 可能下载 Python 3.12。用户也可以使用已安装的 Python 手动部署助手。用户点击扩展中的外部链接时，由浏览器按普通网页访问处理。

本产品不向开发者出售或共享上述本机数据。浏览器自身的同步、下载和历史记录行为由用户的 Chrome 设置与相应服务政策管理。

## 权限

- `nativeMessaging`：与已安装的本机搜索助手通信。
- `storage`：保存上述搜索偏好设置。
- `tabs`：在当前标签页打开用户选中的本地 Markdown 文件。
- `alarms`：定时请求本机助手刷新文件索引。

要从搜索结果直接打开 `file://` 文件，用户还需在 Chrome 扩展详情中单独开启“允许访问文件网址”。扩展没有申请网站主机访问权限。

## 保存与删除

扩展偏好设置由 Chrome 保存，卸载扩展后由 Chrome 处理。本机助手不会随扩展自动卸载；目录配置和 SQLite 索引保存在 macOS 的 `~/Library/Application Support/LocalMarkdownSearch/`，或 Windows 的 `%LOCALAPPDATA%\LocalMarkdownSearch\`。用户可停止使用扩展并移除本机助手注册，再自行删除该数据目录以清除目录配置、索引和选择记录。删除本产品的数据不会删除用户原有的 Markdown 文件。

如需反馈隐私问题，请使用本项目的公开支持入口，不要在公开问题中粘贴私人文件路径、文档正文或凭据。
