# Local Markdown Search

在 Chrome 地址栏输入 `md`、空格和文件名，或打开扩展弹窗，即可搜索自己选定目录中的 Markdown 文件。文件索引和选择记录保存在本机。

使用前需要分别安装 Chrome 扩展与本机搜索助手：下载一键安装包，解压后双击 macOS 的 `setup-macos.command` 或 Windows 的 `setup-windows.cmd`，首次安装时按提示选定搜索目录。安装完成后回到扩展点击“重新检测连接”。若想从结果直接打开文件，还需在 Chrome 扩展详情中开启“允许访问文件网址”。
