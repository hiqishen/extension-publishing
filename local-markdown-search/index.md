# Local Markdown Search

在 Chrome 地址栏输入 `md`、空格和文件名，或打开扩展弹窗，即可搜索自己选定目录中的 Markdown 文件。文件索引和选择记录保存在本机。

使用前需要分别安装 Chrome 扩展与本机搜索助手，并在首次设置时选定搜索目录。若想从结果直接打开文件，还需在 Chrome 扩展详情中开启“允许访问文件网址”。
