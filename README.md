# 扩展发布资料

此仓库通过 GitHub Pages 提供浏览器扩展的公开说明。每个扩展使用独立目录。

## 页面与来源

- Markdown Plus
  - 隐私说明页面：`markdown-plus/privacy.md`；正文与主项目的 `md-reader-editor/PRIVACY.md` 同步，并保留 Jekyll front matter。
  - 本地助手页面：`markdown-plus/native-host.md`。
- Local Markdown Search
  - 隐私说明页面：`local-markdown-search/privacy.md`；正文同步自 `c_utils/chrome-local-markdown-search/PRIVACY.md`，并保留 Jekyll front matter。
  - 本机助手页面：`local-markdown-search/native-host.md`。发布下载包后，在页面补充 GitHub Release 链接和 SHA-256。
